## Reading the numbers

- On the EU-native stack, **telephony is the largest single cost** (≈40% of the per-minute cost, ≈55% including transfers), not AI. Model choice matters only at the
  "larger LLM" tier, which costs ~1.5× per minute — use it only where tests show the small model fails.
- A managed platform (Vapi/Retell) roughly **doubles to 2.5× the variable cost per minute**, before Vapi's EU-region
  package. At 10,000 minutes/month across clients that is ≈ $530/month extra; at 50,000 ≈ $2,600/month.
- Platform fixed costs are small per client beyond ~20 clients. **Infrastructure changes by scale:** 5–20 clients — one
  web deployment, one gateway container, Supabase Pro; 20+ — second gateway instance for redundancy; 100+ — larger
  database compute; 300–500 — more gateway capacity (concurrency, not code changes) and partitioned call tables.
- The "minimum price" table is a floor for a 70% gross margin at full use of included minutes; it is not a pricing
  recommendation. Your price should be set from value to the client (missed calls recovered) and competitor pricing,
  then checked against this floor. Overage per minute should be ≥ 3× the variable cost per minute (≈ €0.12+).

## Not yet in the model

- Croatian SIP carrier rates (assumed €0.01/min) and Croatian number rental (assumed $5/month).
- SMS confirmation costs (per message, country-specific) — add once a provider is chosen.
- Support and onboarding labour (the largest real cost per client at small scale).
- VAT handling: B2B reverse charge vs domestic VAT (see docs/external-actions.md — tax adviser review).
